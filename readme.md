# schnti/legal

Internes Kirby-Plugin für eigene Projekte. Holt Rechtstexte von einer
zentralen API, die nur mit Zugangsdaten erreichbar ist.

Öffentlich nur, weil sich Composer-Pakete so einfacher installieren lassen —
nicht zur allgemeinen Nutzung gedacht, ohne Dokumentation und ohne Support.
